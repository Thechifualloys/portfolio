01 · About

Engineer profile

Backend-first, full-stack when the problem needs it.

I don't just write code — I architect systems. Since founding Chiflloy in 2022, I've focused on bridging the gap between real operational problems and reliable software that solves them.

On the backend, logic is where the work actually happens: using Node.js, Python and robust database design with PostgreSQL and MongoDB, I build engines that stay stable under real usage. On the front end, I use HTML5, CSS3 and JavaScript (React, Vue) to make sure that logic is actually usable.

I've worked across the stack — from custom API integrations and automated inventory systems for e-commerce platforms, to server environments and enterprise-level deployments where uptime and security aren't optional.

Whether it's a hostel management system handling high traffic, a Shopify store that needs its inventory automated, or a backend that just needs to not fall over — that's the kind of problem I like solving.
